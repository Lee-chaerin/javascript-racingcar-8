# javascript-racingcar-precourse
## 기능 목록
### 입력
- [x] 자동차 이름 입력받기
  - [x] 쉼표(,)를 기준으로 자동차 구분
- [x] 시도할 횟수 입력받기
- [x] 잘못된 값 입력 시, Error 처리 후 종료
  - [x] 자동차 이름이 공백인 경우
  - [x] 자동차 이름이 5자를 초과한 경우
  - [x] 자동차 이름이 중복인 경우
  - [x] 횟수 입력 시, 공백인 경우
  - [x] 횟수 입력 시, 0 이하를 입력한 경우
  - [x] 횟수 입력 시, 숫자가 아닌 값을 입력한 경우

### 차수별 실행
- [x] 입력받은 횟수만큼 실행하기
- [x] 랜덤값으로 전진 여부 판별하기
- [x] 자동차별 이동 거리 저장하기
- [x] 경주 종료 후 우승자 판별하기

### 출력
- [x] 차수별 실행 결과 출력하기
- [x] 우승자 안내 문구 출력하기
  - [x] 공동 우승자인 경우 쉼표(,)로 구분하기

### 테스트 코드
- [x] 자동차 이름이 공백인 경우
- [x] 자동차 이름이 5자 이상인 경우
- [x] 자동차 이름이 중복인 경우
- [x] 횟수 입력 시, 공백인 경우
- [x] 횟수 입력 시, 0 이하를 입력한 경우
- [x] 횟수 입력 시, 숫자가 아닌 값을 입력한 경우
- [x] 공동 우승자인 경우
- [x] 올바른 입력값을 넣은 경우
